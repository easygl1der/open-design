Open Design: how to use it

Open Design is our own design workspace. You describe what you want, and Claude Code on the SG machine builds it as a web page, a prototype or a short film. You watch the result appear in a preview and keep changing it by chat.

1. Sign in

  1. Open design.yitwah.site.
  2. Enter your email. Cloudflare sends you a one-time code.
  3. Type the code. Open Design opens.

On a device in our tailnet you can also use https://wri-sg-pc-007.tailc544c9.ts.net:8443, which needs no email code.

2. Start a design

You start from the prompt box on Home.

  1. Write what you want in a sentence or two.
  2. Pick a type: Prototype, Motion design, Slide deck, or one under More. Each type shows example briefs you can use.
  3. Click the palette button to pick a design system (see below).
  4. Press the arrow to send. The agent starts work and opens the project.

The demo stops before sending.

3. Design systems

A design system sets the colours, type and rules the agent follows. There are 152 presets, and our own one is WRISE AI OS.

  • Left rail → Design systems to browse them. Click one to see its palette and type.
  • Your systems holds WRISE AI OS. Official presets holds the 152 others, with search.
  • Create makes a new one from a DESIGN.md, a website or a brand.

4. Skills and @

Skills are instructions the agent can follow for a kind of work, such as a magazine layout or a pitch deck. There are 255 of them.

  • Left rail → Plugins → Skills lists them, with search and categories.
  • To use one, type @ in the prompt box and pick it from the list.

5. Working folder

The working folder lets the agent read your own files, for example notes or a brand guide, while it designs.

  1. Under the prompt box, click Working directory → Choose folder.
  2. Type a folder path on the SG machine, for example /Users/wriseai/Projects/wrise-docs, and press OK.

6. Project view and export

A project has the chat on the left and the live preview on the right.

  • Desktop menu: switch the preview to Tablet or Mobile.
  • Design Files tab: every page, script and image in the project.
  • Export: PDF, image, .zip, or one standalone HTML file.
  • The comment button lets you pin notes on the preview.
  • To change something, write it in the chat box and send.

7. Motion to MP4

Pick Motion design on Home. The agent builds the animation and renders it to film.mp4 in the project.

  • Open the MP4 card in the chat to watch it, or download it.
  • The animation source stays in the project, so you can ask for changes and render again.

8. Community templates

Left rail → Community shows finished templates by type. Hover a card for two buttons:

  • Remix copies the template into a new project, with its prompt waiting in the chat box. Edit it, then send.
  • Try it now puts the template's prompt into the Home box.

9. Memory

  • Every project keeps its full chat history. It stays even if Claude Code sessions on SG are cleaned up.
  • Learning from chats is on, so a preference you state in one project carries into new chats. You can see and edit what was saved in Settings → Memory.
  • To reuse another project's style, either turn it into a design system (Design systems → Create), or set that project's folder as the working folder.

10. Settings

  • Models & providers → Local CLI: shows Claude Code, the agent that does the work.
  • Memory: saved facts and preferences, with an on/off switch.
  • Media providers: image, video and audio generation. These need API keys (not set yet).
  • OpenDesign MCP: how Claude Code connects to Open Design.

11. From Claude Code on SG

Any Claude Code session on the SG machine can use Open Design through its tools: create_project, start_run, get_run and list_files. Run claude in any folder and ask in plain words:

cd ~/Projects/wrise-docs
claude
> Use open-design to make a one-page landing for a kopi shop, then list the files.

The new project shows up in Open Design like any other, so you can open it in the browser and keep going there.

12. What doesn't work yet

  • Image and audio generation need API keys in Settings → Media providers. None are set yet.
  • Share links need an Open Design Cloud sign-in, which is not set up. Use Export instead.
  • Claude Code is the only agent. The other CLIs listed in Settings are not installed.
